This folder contains free VFX packages from the Unity Asset Store. However, they're not licensed for distribution, so you need to add your own copies. The packages are:
- https://assetstore.unity.com/packages/p/fx-lightning-ii-free-25210
- https://assetstore.unity.com/packages/vfx/particles/hit-effects-free-284613
- https://assetstore.unity.com/packages/vfx/particles/spells/status-and-auras-free-289450

The demo will work fine without these, but VFX will be missing
